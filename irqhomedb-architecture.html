irqhomedb — Inventory Rumah Irza

FastAPI + SQLite · Local network · Mobile-first · Multi-user

🧑‍🤝‍🧑 Siapa?

  • • Irza — pemilik rumah, organizer utama
  • • Asisten — ikut mengelola dan mencari barang
  • • Kedua akses dari laptop & HP via browser
  • • Login sederhana (username + password)

⚙️ Stack

  • • Backend: FastAPI (Python 3.11+)
  • • Database: SQLite + SQLAlchemy ORM
  • • Frontend: Jinja2 templates + vanilla JS
  • • CSS: Tailwind (CDN) atau custom responsive
  • • Photos: File system + thumbnail cache

🗂️ 7 Tables Database

  • • Item — nama, status (unidentified→identified), lokasi, stok
  • • Category — hierarki bebas, many-to-many dgn Item (tag-like)
  • • ItemCategory — junction table (item ↔ banyak kategori)
  • • Location — hierarki ruang (parent, room)
  • • ItemPhoto — unlimited per item, type=part/box, no "primary"
  • • ItemLog — audit trail perubahan
  • • User — username + password hash
